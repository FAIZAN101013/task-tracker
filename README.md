# MERN Task Tracker

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB Atlas

## Features
- Create Task
- View Tasks
- Update Task
- Delete Task
- Responsive UI
- REST API
- MongoDB Integration
